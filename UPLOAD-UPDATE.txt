KneeFit v2 update

In GitHub, open the kneefit repository and replace/upload these files at the repository root:
- index.html
- manifest.json
- service-worker.js
- icons/ folder (icons are unchanged, but safe to keep/upload)

The two files that must change are index.html and service-worker.js.
Commit the changes to the main branch. GitHub Pages will redeploy automatically.
If the Home Screen app still shows the old interface after deployment, fully close KneeFit and reopen it. The v2 service worker uses a new cache name and should refresh the app.
